功能详解

系统功能

双通道高速采样 ADC + DMA
  • 利用 ADC + DMA 实现双通道完全同步采样，最高采样率 2.8 Msps
  • 支持 21 种采样率一键切换，适配不同频率信号测量需求
  • DMA 缓冲区分配于普通 SRAM（CCM RAM 不支持 DMA），保证数据搬运稳定
频谱分析与数字滤波 ARM DSP
  • 基于 ARM DSP 库实现 2048 点 FFT 运算，实时显示信号频谱
  • 设计 21 阶 FIR 低通滤波器，支持多档截止频率选择，有效抑制高频噪声
  • FFT 与滤波均在 DSP 专用指令集加速下完成，计算延迟极低
UI 交互与参数测量 STemWin
  • 基于 STemWin 图形库设计示波器 UI，支持波形缩放、平移
  • 双游标测量：自动计算峰峰值（Vpp）、RMS 电压、信号频率等参数
  • 支持自动触发与普通触发两种模式，实时游标指示触发位置
SD 卡截图存储 FatFS
  • 利用 FatFS 文件系统，支持将当前屏幕截图以 BMP 格式保存至 SD 卡
  • 截图任务通过任务通知机制异步触发，写卡过程不阻塞主界面刷新
技术难点与解决方案

攻坚过程

难点 1 — 波形数据与 GUI 的数据竞争

波形数据处理任务与 GUI 刷新任务同时访问波形缓冲区，早期出现显示撕裂（画面局部刷新）。解决方案：引入 FreeRTOS 事件标志组，DSP 处理完成后再发出标志通知 GUI 任务刷新，彻底消除竞争问题。

难点 2 — 截图写卡阻塞主界面

SD 卡写入速度较慢（数百毫秒），早期同步写入导致界面明显卡顿。改为任务通知机制异步触发截图任务，写卡在后台独立执行，主界面刷新完全不受影响。

难点 3 — 多任务串口日志乱序

多个任务同时调用 printf 输出日志，内容相互穿插导致日志不可读。使用互斥信号量保护 printf 资源，同一时刻只允许一个任务占用串口输出，彻底解决日志乱序问题。

难点 4 — CCM RAM 与 DMA 不兼容

STM32F429 的 64KB CCM RAM 访问速度快，但硬件上不支持 DMA 访问。通过合理规划内存布局：任务栈分配至 CCM RAM 提升调度效率，ADC 的 DMA 缓冲区则分配至普通 SRAM，兼顾了性能与功能正确性。
