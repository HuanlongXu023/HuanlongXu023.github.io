PROJECT_01
智能手表
Smart Watch · 2025.09 — 2025.12 · 个人项目

基于 STM32F411 + FreeRTOS 的完整智能手表，集成多传感器、三级功耗管理与 OTA 无线升级，实现了从 UI 框架到低功耗唤醒的全栈嵌入式开发。

STM32F411CEU6 FreeRTOS LVGL BLE (KT6368A) OTA EEPROM 低功耗
  • 集成 MPU6050（计步/抬腕唤醒）、EM7028（心率）、SPL06-001（气压/海拔）、LSM303DLHC（电子罗盘）四种传感器，统一管理驱动层
  • 实现三级功耗管理：正常运行 70–80 mA → 屏幕变暗 → MCU STOP 休眠 1 mA，通过 RTC 定时中断 + 抬腕手势智能唤醒
  • 设计 Bootloader / APP 双分区，支持通过蓝牙模块 KT6368A 进行 OTA 无线固件升级
  • 使用 FreeRTOS 消息队列解耦按键、充电检测、传感器数据等模块，通过 IdleBreak 机制统一管理屏幕休眠计时器

PROJECT_02
双通道数字示波器
Dual-Channel Digital Oscilloscope · 2025.03 — 2025.07 · 个人项目

基于 STM32F429 的双通道示波器，ADC+DMA 实现最高 2.8 Msps 同步采样，集成 2048 点 FFT 频谱分析与 21 阶 FIR 滤波，支持波形缩放、游标测量及 SD 卡截图存储。

STM32F429 FreeRTOS STemWin FatFS ARM DSP Lib ADC+DMA FFT / FIR
  • ADC + DMA 双通道同步采样，最高采样率 2.8 Msps，支持 21 种采样率一键切换
  • 基于 ARM DSP 库实现 2048 点 FFT 实时频谱；设计 21 阶 FIR 低通滤波器，多档截止频率可选
  • 通过事件标志组同步 DSP 处理与 GUI 刷新任务，彻底消除波形显示撕裂；截图任务异步写 SD 卡，不阻塞主界面
  • 合理规划 CCM RAM / SRAM 布局：任务栈分配至 64KB CCM RAM 提升调度效率，DMA 缓冲区分配至普通 SRAM

PROJECT_03
智能闹钟
Smart Alarm Clock · 2024.03 — 2024.06 · 个人项目

基于 STM32F429 + FreeRTOS 的网络闹钟，接入心知天气 API 实时获取天气数据，OLED 显示时间与天气，完整实践了多任务协同、资源互斥与低优先级任务调度。

STM32F429 FreeRTOS ESP8266 HTTP API RTC OLED (I²C)
  • 利用 RTC 外设实现精准时钟与闹钟功能，到时蜂鸣器自动提醒，支持按键设置
  • 通过 ESP8266 联网，调用心知天气 REST API 获取指定城市实时天气，OLED 实时显示
  • 合理分配任务优先级：显示任务高优先级避免卡顿，天气读取任务低优先级；为数据缓存大的任务配置充足堆栈，防止系统卡死
  • 使用互斥量保护 I²C 总线资源，队列消息实现显示任务与数据读取任务的安全同步
